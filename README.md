# 📝 TaskNet

Một ứng dụng **quản lý công việc (ToDoList)** đơn giản, giúp người dùng tạo, chỉnh sửa, đánh dấu hoàn thành và xóa công việc một cách dễ dàng.

---

## 🚀 Tính năng
- ➕ Thêm công việc mới  
- ✏️ Chỉnh sửa công việc  
- ✅ Đánh dấu công việc đã hoàn thành  
- ❌ Xóa công việc  
- 💾 Lưu trữ dữ liệu (có thể dùng localStorage hoặc kết nối database tuỳ phiên bản)  

---

## 🛠️ Công nghệ sử dụng
- **Frontend**: React / HTML / CSS / JavaScript  
- **Backend** (tùy chọn): Node.js + Express  
- **Database** (tùy chọn): MongoDB
